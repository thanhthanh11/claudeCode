# Quy tắc JPA entity (Oracle, Hibernate `ddl-auto=validate`)

- Luôn khai báo `@Table(name = "...")`; tên bảng/cột UPPER_SNAKE_CASE.
- Khóa chính: `@GeneratedValue(strategy = GenerationType.IDENTITY)` ứng với `ID NUMBER(19) GENERATED BY DEFAULT AS IDENTITY`.
- Thời gian dùng `LocalDateTime` (không dùng `Instant`), `@CreationTimestamp` / `@UpdateTimestamp` cho `CREATED_AT`, `UPDATED_AT`.
- Cột `CHAR(3)` (currency): thêm `@JdbcTypeCode(SqlTypes.CHAR)`.
- Cột boolean `NUMBER(1)`: bắt buộc `@Convert(converter = NumericBooleanConverter.class)` (Oracle 23 trong IT có BOOLEAN native).
- Tiền: `BigDecimal` với `NUMBER(19,4)`.
- Không tạo quan hệ JPA/FK sang schema của service khác — chỉ lưu ID/mã.
- Cột PII: `@Convert(converter = EncryptedStringConverter.class)` (Hibernate lấy converter qua Spring nên `@DataJpaTest` phải nạp `CommonCryptoConfig` + `bank.security.encryption.key`), độ dài cột đủ cho ciphertext (`enc:v1:` + Base64 ≈ 1,4 × độ dài gốc + 40). Cần tìm / unique → thêm cột `*_HASH VARCHAR2(64 CHAR)` (`BlindIndexer`), không query trên cột mã hóa.
- Mọi thay đổi cột phải có script migration tương ứng trong `database/oracle/` (xem skill `add-oracle-migration`).
